# 节点监控 0.1.0 便携版

将**整个文件夹**放到你希望保存程序和数据的位置，然后双击 `build/节点监控.app`。不要单独移动 `.app`，程序需要同一文件夹中的 `.nodemon-project` 标记来确定数据位置。

本发行包不带任何主机的令牌、历史或连接设置。首次打开选择“添加服务器”；Linux 采集端使用单独提供的 amd64 / arm64 包，步骤见 `docs/部署与使用.md`。也可以选择“先体验演示”，界面将明确显示模拟数据；退出应用后演示服务结束。

服务器在其他网络且没有公网入口时，可参照 `docs/Tailscale远程连接.md` 配置私有远程连接。Tailscale 已集成在 Mac 应用和新版 Linux 采集端里，无需另外安装客户端；两端首次需要分别授权，服务器需要更新采集端。

要求 Apple Silicon Mac、macOS 14 或更新系统；本次实测 macOS 26.5.2。无需安装 Go、Swift、Docker、Python 或其他运行时。应用为本地临时签名版本，尚未办理 Apple Developer ID 签名和公证，系统仍可能提示确认来源与局域网访问权限。

菜单栏显示所选服务器摘要，关闭完整监控窗口后仍继续工作。工具栏可开启桌面挂件；拖动挂件标题可移动，右键切换大小，设置里可调整透明度、置顶、锁定和节能模式。

应用激活时，`⌘0` 打开监控台，`⌘1` 打开菜单栏面板，`⌘,` 打开设置。

数据保存在本文件夹的 `data/`，其中有私密访问令牌。退出程序后可备份；删除整个文件夹即可移除本机项目文件。远程 Linux 采集端需另外停止并删除其独立目录。

本包只含运行程序和说明；完整源码、测试与构建脚本见单独的 `NodeMonitor-source.zip`。
